# micahreich.github.io

Personal website. Plain static HTML (no build step), served by GitHub Pages.

- `index.html` — all content (bio, highlights, publications/projects, talks, misc)
- `style.css` — theme
- `images/` — profile photo (`profile.jpg`) and thumbnails
- `files/` — CV/resume PDF

Each item belongs to a tab via its class (`highlight`, `publication`, `talk`, `misc`).

Template adapted from [Jason Lee](https://jasonlee328.github.io) / [Andy Zeng](https://andyzeng.github.io/), inspired by [Jon Barron](https://jonbarron.info/).
